## ✨ Features

Key functionalities and highlights of the system:

| Feature | Description |
|---|---|
| 🛏️ **Real-time bed availability** | General, ICU, Oxygen, Ventilator |
| 📍 **Google Maps** | Nearby hospitals with GPS |
| 🚨 **Emergency SOS** | SMS alert to the 3 nearest hospitals |
| 📊 **Analytics** | Peak emergency hours charts |
| 🔐 **Secure login** | JWT + bcrypt + Google Login |
| 📱 **SMS alerts via Fast2SMS** | Email verification via Resend.com |

---

## 🏨 Hospital Management

Manage hospitals, appointments and notifications efficiently.

| Feature | Description |
|---|---|
| 📝 **Hospital Registration & Approval** | Self-serve onboarding with admin approval workflow |
| 📅 **Appointment Booking** | With doctor & time-slot selection |
| ✉️ **Email Notifications** | Appointment confirmations & hospital approval emails |
| 🔳 **QR Code Check-in** | Scan-to-verify appointment system for hospital reception |
